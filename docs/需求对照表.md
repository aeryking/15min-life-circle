## 二、API 深度调用与工程优化（30%）

| 细则 | 实现 | 量化结果 |
|---|---|---|
| 合理应用**批量距离矩阵计算**或**并发请求策略**，显著降低耗时 | 所有两点距离都通过批量算路完成；分块规划、配对调度（按设施 / 按点位自动选择）；等时圈与 POI 并发；SSE 流式推送；结果级缓存与相同请求合并 | 每次体检 88–106 次请求，逐点调用需要 873–1176 次，**节省约 90%**；批量因子 13–22 元素/请求；缓存命中 0.5 s 出结果 |
| POI 检索缺失、API 返回异常、QPS 限流时的**异常捕获与兜底** | 检索结果被分页截断时，对盲区片区**定点复核检索**补回遗漏设施；错误分类（临时 / 限流 / 配额 / 鉴权 / 参数）；指数退避重试；AIMD 自适应限流；按服务熔断；多级降级链路；回放模式；开源底图降级；**故障演练开关** | 注入 20% 网络失败 + 10% 限流，结果与无故障时一致（`tests/replay-e2e.test.js`）；[地图 API 调用策略 §5–§9](./地图API调用策略.md) |
| **创新的空间插值**：不获取底层路网，通过分散点位测时结果做空间插值或扇形采样 | 扇形多环采样 + 割线法自适应加密；λ / 绕行增量两种插值量；极坐标各向异性 IDW（LOOCV 从 48 组超参数中自动选择）⊕ 极坐标双线性集成；伪岛剔除；一次采样生成三类人群等时圈 | 独立检验点 MAE 59–126 m，直线画圆为 366–534 m；[等时圈生成算法](./等时圈生成算法.md) |
| 插值精度可现场验证 | 测时探针「🎯 实测验证」：地图上任意点击，1 次批量算路获取实测值，与插值估算并排显示误差、圈内外判定是否一致，并累计平均误差 | 可当场抽检，无需依赖文档数字 |

## 三、产品交互与用户体验（15%）

| 细则 | 实现 |
|---|---|
| 多社区对比看板 | 10 个社区 × 34 项指标：排名赛道、象限气泡图、体检热力矩阵、步行时间分布、六维画像墙、自动洞察，跨图表联动高亮 |
| 数据可视化（热力图、柱状图、雷达图等） | 步行时间热力、六维雷达（成年人 vs 老年人）、设施数量与覆盖率柱状图、盲区占比、判定方式构成堆叠条、分阶段耗时；配色经 dataviz 校验脚本验证（全配对正常视觉 ΔE ≥ 15，另有图标与文字作为二级编码） |
| 地图交互流畅 | 流式渲染（等时圈先出图）；图层开关；设施分类筛选；点击行 / 问答结果在地图上定位；**测时探针**；结果数据不做深度响应式代理，降低渲染开销 |
| 页面可分享 | 每份报告、打印页、对比组合、体检历史都有独立地址（`/r/:id`、`/r/:id/print`、`/compare?ids=`、`/history`），刷新不丢失、可收藏分享、支持浏览器前进后退 |
| 界面美观、可自定义中心点、操作逻辑清晰 | 「选点 → 参数 → 体检」三步流程；进度条与阶段清单；搜索联想、地图点选、定位、预置社区；未配置 AK 时有明确提示 |
| 暗黑模式 | 一键切换，默认跟随系统；地图底图、覆盖物、图表同步切换；深浅两套配色分别校验（深色全配对正常视觉 ΔE ≥ 15、对比度 ≥ 3:1） |
| 额外能力 | 多轮流式 AI 问答（逐字输出、可选深度思考并展示思考链、支持追问，对话按访客隔离并持久化）、适老化与亲子友好评估（三视角评分）、补点选址、多社区对比、可打印报告、GeoJSON 导出 |
